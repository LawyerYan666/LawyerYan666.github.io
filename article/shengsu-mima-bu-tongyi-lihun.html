💡 高频争议

想离婚却被对方"死活不同意"拖住，是上海法院最高频的家事诉讼困局。以下五个高频争议，决定这婚离不离得掉：
  1. 第一次起诉、对方不同意，就一定判不离吗？

—— 几乎一定。样本中 8 件判不离全为"首次起诉 + 被告不同意 + 仅性格不合 / 生活琐事"，法官没有自由裁量空间。

  1. 分居多年、二次起诉，法院必须判离吗？

—— 是。长期分居（5 年 +）、三次起诉、家暴 + 保护令，任一出现判离率接近 100%。

  1. "假离婚"买房的财产协议有效吗？

—— 为购房 / 避税签的协议，财产条款若被认定虚假意思表示，全部无效，房屋恢复共有。

  1. 发现对方婚内给第三者买房、隐匿财产，离婚后能再分吗？

—— 能。为第三人买房并隐瞒属转移，离婚后可诉请再分。

  1. 离婚协议里的违约金、保证金，法院认吗？

—— 认。协议自愿签署、内容明确，违约金 / 保证金可全额支持（如 20 万保证金 + 10 万违约金）。

2.4 要点速记

  1. 判离——50% 但绝非"碰运气"：8 件判离案全部附带硬证据（分居5年、家暴+保护令、三次起诉、被告缺席），无一例外
  2. 判不离——50% 全是同一种剧情：首次起诉 + 被告不同意 + 理由仅限于"性格不合、生活琐事"，从2009年到2020年无本质变化
  3. 离婚后财产类——高支持率（85.7%）：只要未超时效、有财产线索，基本获支持；唯一驳回案系双重硬伤（协议已约定+超时效）
  4. 核心结论：第一次起诉+只有琐事=大概率判不离；第二次起诉+持续分居+足够证据=一定能判离

四、法院裁判规则

规则 1：首次起诉 + 被告不同意 + 仅琐事 → 一般判不离

这是离婚诉讼第一条铁律。 23 件样本中，8 件判不离全部符合该特征——不是法官不想判，是原告拿不出法律认可的"感情破裂"证据。

  • 依据：《民法典》第 1079 条（原《婚姻法》第 32 条）——感情破裂为判离前提
  • 案例：(2020)沪0112民初27152号 徐某诉秦某，疑婚外情无实据、被告不同意 → 不准离婚
  • 案例：(2019)沪0113民初18511号 刘某某诉陈1，感情破裂无充足证据 → 不准离婚
  • 案例：(2011)杨民一(民)初字第2384号 张某诉沈某，琐事、被告不同意 → 不准离婚
  • 案例：(2019)沪0113民初21109号 范某某诉顾1，生活琐事依据不足 → 不准离婚
  • 案例：(2017)沪0106民初42994号 何某诉陈某某，琐事无根本矛盾 → 不准离婚
  • 案例：(2020)沪0116民初16032号 俞某某诉蔡某某，照顾小孩琐事无证据 → 不准离婚

规则 2：长期分居 → 判离

分居是最有力的"感情破裂"证据。样本中分居5年以上案件全部判离。

  • 依据：《民法典》第 1079 条——因感情不和分居满二年应准予离婚
  • 案例：(2020)沪0120民初14952号 韩某某诉姜某1，分居5年和好无望 → 准予离婚
  • 案例：(2012)杨民一(民)初字第5412号 陈某诉某某，2008年起分居、被告缺席 → 准予离婚

规则 3：家暴（报警/保护令/伤情）→ 判离

有完整家暴证据链的案件，法院毫不迟疑判离。

  • 依据：《民法典》第 1079 条——实施家庭暴力调解无效的，应准予离婚
  • 案例：(2019)沪0113民初14946号 马1诉王某，家暴+人身保护令+分居+被告同意 → 准离；车折9万、公积金折7万

规则 4：多次起诉 + 持续不和 → 判离

第三次起诉几乎是判离的"底牌"。法院逻辑：给你两次机会修复婚姻，第三次再来说明确实破裂。

  • 依据：《民法典》第 1079 条——判决不准离婚后双方又分居满一年，一方再次起诉的，应当准予离婚
  • 案例：(2017)沪0120民初1156号 王某诉黄某1，三次起诉+长期分居 → 准予离婚
  • 案例：(2020)沪0117民初9326号 蒋某某诉席某某，三次起诉不和后 → 准离；补偿3.5万

规则 5：二次起诉仍可判不离（2015年前更常见）

即使第二次起诉，若证据不足且被告有和好意愿，法院可能再给一次机会。但2017年后趋严。

  • 依据：感情破裂须有法定情形支撑，非起诉次数本身
  • 案例：(2015)松民一(民)初字第9763号 杨某甲诉严某甲，彩票欠债+琐事，二次仍不准 → 不准离婚

规则 6：被告缺席/无和好意愿 → 判离

对方不露面、不表态、不挽回，本身就是感情破裂的佐证。

  • 依据：被告经传票传唤无正当理由拒不到庭可缺席判决；无和好意愿佐证感情破裂
  • 案例：(2017)沪0101民初205号 陈某某诉戴某某，再次起诉、被告缺席 → 准予离婚
  • 案例：(2013)闵民一(民)初字第8401号 王a诉康a，被告无和好意愿 → 准予离婚
  • 案例：(2018)沪0101民初7134号 徐某诉陈某1，无共同生活愿望 → 准予离婚

规则 7："假离婚"的财产协议——虚假意思表示 → 无效

为购房/避税办理的假离婚，财产分割条款如被认定为"虚假意思表示"，全部无效。

  • 依据：《民法典》第 146 条——行为人与相对人以虚假意思表示实施的民事法律行为无效
  • 案例：(2020)沪0115民初88289号 谢某2诉邓某某，为购房假离婚，财产条款系虚假意思 → 无效，房屋为共有

规则 8：明知未分割 ≠ 隐匿财产

双方都清楚有某财产但没写进协议 → 不属于隐匿，只能主张正常分割。

  • 依据：隐匿须以"隐瞒、转移"为要件；明知未分割属约定遗漏，非隐匿
  • 案例：(2017)沪0112民初24846号 王某某诉郭某某，假离婚时明知车辆未分割 → 车辆平均分割、折1.5万

规则 9：隐藏/转移财产 → 离婚后可再分

婚内为第三人买房并隐瞒，属于隐藏/转移夫妻共同财产，离婚后仍可诉讼再分割。

  • 依据：《民法典》第 1092 条（原《婚姻法》第 47 条）
  • 案例：(2010)沪二中民一(民)终字第2120号 马某某诉冯甲，为第三人买房隐瞒 → 隐藏/转移，判付10万

规则 10：协议自愿+内容明确 → 有效，违约金/保证金可获支持

只要协议自愿签署、内容明确，法院坚决维护协议效力。

  • 依据：《民法典》第 464 条、第 585 条——依法成立的合同及违约金条款有效
  • 案例：(2017)沪0109民初6927号 徐某某诉陈某1，协议有效无胁迫 → 过户+保证金20万+违约金10万，全额支持
  • 案例：(2024)沪0106民初26580号 刘某诉谈某，美国判决+公证协议有效 → 房产归原告
  • 案例：(2015)沪一中民二(民)终字第928号 李某2等诉李泳霖，委托父亲签协议有效、无胁迫 → 驳回上诉

五、律师实务建议

5.1 离婚诉讼防坑清单（撰写与举证重点）

  1. 首次起诉别只会说"性格不合"：必须围绕法定破裂情形举证，否则大概率判不离。
  2. 家暴案三件套缺一不可：人身保护令 + 报警记录 + 伤情病历，三者齐备判离最稳。
  3. 想判离，优先"二次起诉 + 持续分居"组合：一诉判不离后，分居满一年再诉，判离概率大幅提升。
  4. 假离婚财产协议有无效风险：为购房 / 避税签的协议，财产条款可能被认定虚假意思表示而无效。
  5. 离婚协议尽量兜底：违约金 / 保证金条款写清，自愿签署即获支持。

5.2 起诉策略（按场景）

场景策略要点
首次起诉，预感对方不同意做好"判不离"准备，重点是部署分居证据，6个月后再诉。切忌情绪化陈述"性格不合"——那等于白起诉
家暴案先申请人身保护令，同步固定报警记录、伤情照片、病历——三件套缺一不可
被告拖延/玩失踪利用缺席判决制度，做好传票送达记录
财产涉第三人申请另案处理，不要困在本诉里拖延
想确保判离"起诉次数 + 持续分居"是最稳组合——二诉+分居=近乎稳赢

5.3 证据准备清单

类型必收证据
感情破裂结婚证；分居证明（租房合同/水电记录）；历次判决书（如有）；家暴（报警记录/保护令/病历/伤情照）；出轨证据（须明确，非"怀疑"）
子女抚养出生证；收入证明；住房证明；就读证明；对方不适合抚养证据（家暴/酗酒/赌博/拒不支付抚养费）
财产分割房产证；车辆登记；银行流水；公积金明细；股权凭证；隐匿线索（异常大额转账/置业合同）
协议履行离婚协议书（民政局备案版）；公证书；催款记录（微信/短信）；违约金计算依据

5.4 诉讼请求设计 & 庭审表达

诉讼请求庭审表达重点
①离婚 ②抚养（随谁+抚养费） ③财产分割（逐项列明） ④过错赔偿 ⑤诉讼费围绕"感情确已破裂"组织证据，避免用"性格不合"；家暴/出轨出示原始证据，切忌"怀疑"式陈述；抚养主打"子女利益最大化"四件套（出生证+收入+住房+就读）；财产讲清出资→登记→使用的完整链条；被告当庭不同意时，立刻亮出"分居证据"证明无和好可能

5.5 庭审表达重点

  1. 咬定"感情确已破裂"：不要讲"他脾气不好、不干家务"，要讲"自X年X月分居至今、已第X次起诉、有家暴报警记录/保护令"
  2. 抚养权聚焦"子女利益最大化"：四证齐全（出生+就读+收入+住房），这是硬通货
  3. 财产逐项列明：房产（地址+登记+出资）、车辆（登记+折价）、公积金（明细）、存款（流水），一项不能少
  4. 被告说"不同意离"：不纠缠"为什么不同意"，直接回应"我们有分居证据/已多次起诉/对方无和好意愿"
