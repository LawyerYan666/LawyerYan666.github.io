2.3 要点速记

  1. 100% 认定无效——毫无例外：26 件样本中，没有一家法院、没有一个法官认定过婚外情赠与有效。这是上海法院最统一的裁判立场
  2. 92% 全额返还——偶有例外但极少：仅 2 件未能全额返还，原因均为部分转账的性质存在争议（如确有共同消费支出），非法院对赠与行为本身有不同看法
  3. LPR 利息——2023 年起标配：从 2023 年开始，上海法院普遍支持"按 LPR 计算资金占用损失"，即不仅要还本金，还要赔占用期间的利息
  4. 实物也可追回：不仅转账要还，房、车、奢侈品等实物赠与，同样判令返还实物或折价款

四、法院裁判规则（10条铁律）

规则 1：婚外情赠与因违背公序良俗而自始无效

这是所有案件的基础逻辑。丈夫在婚姻存续期间，擅自将夫妻共同财产赠与婚外第三者，既侵害了妻子的共同财产权，又违背了社会公序良俗。赠与行为自始无效。

  • 依据：《民法典》第153条第2款（违背公序良俗的民事法律行为无效）；第299条（夫妻共同共有）；2024年《婚姻家庭编解释（二）》第7条
  • 案例：浦东法院 2019 年某案，丈夫向婚外第三者转账 1440 万元，法院认定赠与行为整体无效，判令全额返还

规则 2：520、1314 等特殊金额是最有力的定性证据

当转账金额出现 520、1314、9999 等具有特定情感含义的数字时，法院直接认定为赠与——这些数字本身就是赠与意图的最佳佐证。

  • 案例：(2022)沪0115民初56615号 浦东法院，丈夫向第三者转账 109 笔 + 36 笔红包，金额包括大量 520、1314、9999，法院认定"赠与特征明显"，判令全额返还 67.65 万元

规则 3："这是借款"抗辩一律失败

被告最常用的抗辩——"这是借款"，在 26 件样本中无一成功。法院的三段论：没有借款协议 → 没有催讨记录 → 转账附暧昧留言 → 不符合借款特征。

规则 4："这是劳动报酬"抗辩同样失败

没有劳动合同、没有工作对价、没有社保记录——这三点不满足任何一条，劳动报酬主张即告失败。

规则 5："我不知道他已婚"不构成善意第三人

年龄差距明显、交往时间极短即收取大额财物——法院认为"应当知道"或"有理由怀疑"对方已婚。"善意"不成立。

规则 6：离婚后仍可追索——全额返还，不按份额

这是上海法院的重要立场。即使已经离婚，婚姻存续期间发生的赠与仍可全额追回，而非只能追回 50%。

  • 案例：(2020)沪01民终9305号 上海一中院，二审改判——妻子发现前夫在婚姻存续期间给第三者转了 40 万元，但此时已离婚。一审仅判返 50%（按按份共有），二审改判全额返还。判决要旨："违背公序良俗的行为自始无效，离婚协议不能对抗。不应该在个案中'分割'共同财产。"

规则 7：LPR 利息自 2023 年起成为标配

不仅本金要还，资金占用期间的利息损失也一并支持。按中国人民银行同期贷款市场报价利率（LPR）计算。

  • 案例：(2024)沪0106民初14132号 静安法院，返还 14.13 万元 + LPR 利息
  • 案例：(2024)沪0117民初15582号 松江法院，返还 294.62 万元 + LPR 利息

规则 8：实物赠与（房、车、奢侈品）也可追回

不仅转账要还，用共同财产购买的车、房、奢侈品也一样。

  • 案例：(2024)沪0115民初77063号 浦东法院，返还 103.98 万元 + 大众汽车一辆

规则 9：2024 年新司法解释——法律依据更加明确

最高人民法院《关于适用〈民法典〉婚姻家庭编的解释（二）》第7条直接规定：夫妻一方擅自将共同财产赠与第三人的行为无效。 上海法院 2024 年后多份判决直接援引该条，裁判更加统一有力。

规则 10：赠与行为"整体无效"——不拆分、不折算

法院认定赠与行为"整体无效"，而非逐笔辨析。"婚外情人关系中的赠与行为是一个整体，不应分割认定。"这对原告极为有利——不需要逐笔证明每一笔转账的性质。

五、律师实务建议

5.1 取证清单（按优先级排列）

优先级证据类型具体内容取证要点
★★★转账流水银行流水、微信/支付宝转账记录重点标注 520、1314、9999 等特殊金额；标注转账时间（有无与特殊日期重合）
★★★聊天记录微信/短信中的暧昧称呼、提及婚姻关系完整截图，含对方微信号/手机号；不要删任何"借款""生意"等伪装对话（这些都是对方心虚的证据）
★★☆男方自认悔过书、承诺书、保证书尽可能详细：写明与第三者的关系、转账金额、时间；最好有亲笔签名
★★☆特殊日期证据情人节、七夕、生日当天的转账日历截图 + 转账记录配对
★★☆同居/开房证据租房合同、酒店记录、合照注意取证方式合法性
★☆☆第三者身份姓名、身份证号、住址、工作单位用于确定被告

5.2 起诉策略

案由选择策略要点
赠与合同纠纷首选案由。 原告：原配方；被告：第三者 + 丈夫（共同被告或第三人）。诉求：确认赠与行为无效 + 全额返还 + LPR 利息
不当得利备选案由。适用于已离婚或无法完整举证婚外情关系的情况
离婚后财产纠纷如已离婚且涉及房产/车辆等大额实物，可一并列入

5.3 诉讼请求设计

标准版（转账类）：

  1. 确认被告XX与被告XX（丈夫）之间的赠与行为无效
  2. 判令被告XX（第三者）返还受赠款项人民币 XX 元
  3. 判令被告XX支付资金占用损失（以 XX 元为基数，自 X 年 X 月 X 日起按全国银行间同业拆借中心公布的同期贷款市场报价利率 LPR 计算至实际清偿之日止）
  4. 本案诉讼费由被告承担

进阶版（含实物）： 在上述基础上增加：

  • 判令被告返还 XX 车辆（车牌号）/ XX 房产 / XX 奢侈品原物
  • 如无法返还实物，判令折价赔偿人民币 XX 元

5.4 庭审抗辩预判——对方四句话全拆

被告抗辩你的反击核心依据
"这是借款"请被告出示借款协议、还款计划、催讨记录——没有任何一项，借款之说不能成立借款需双方合意 + 实际履行，举证责任在被告
"这是劳动报酬/生意往来"请被告出示劳动合同、工作成果、社保记录——没有对价，不是报酬劳动报酬需有真实劳动关系和对应劳动
"我不知道他已婚"年龄差距 XX 岁、交往 XX 天即收取 XX 万元——不符合正常交往逻辑，善意第三人不成立"应当知道"标准，结合客观事实综合判断
"已经离婚了，只能还一半"援引上海一中院(2020)沪01民终9305号改判案例——公序良俗行为自始无效，离婚不能对抗，应全额返还共同共有≠按份共有；公序良俗无效≠部分无效

5.5 庭审表达重点

  1. 围绕"违背公序良俗"展开：不是"他不爱我了"，而是"婚姻存续期间与婚外第三人建立不正当关系，将巨额共同财产赠与该人——三重违法：侵害配偶财产权、违反夫妻忠实义务、违背公序良俗"
  2. 重点标注"特殊金额"：520、1314、9999、8888——这些数字本身就是最强证据，直接定性为"具有特定情感含义的赠与"
  3. 引用2024年新司法解释：《婚姻家庭编解释（二）》第7条是最新最强法律武器
  4. 反驳"不知情"用客观标准：年龄差 + 交往时间短 + 收款金额大 + 无正常恋爱程序 = 应当知道
