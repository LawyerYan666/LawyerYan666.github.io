1.2 审级与年份

  • 审级：基层法院一审约 72%，中级法院二审（含维持/改判）约 28%
  • 年份跨度：2009 年 — 2024 年，近 70% 集中于 2013—2020 年
  • 裁判倾向总体特征：离婚协议对双方具有法律约束力为绝对前提（婚姻法解释二第8条）；以"欺诈、胁迫"为由撤销协议需严格举证（第9条），且受一年除斥期间限制；抚养费调整采"儿童利益最大化 + 实际需要 + 父母负担能力"标准

2.2 要点速记

  1. 协议履行类——高支持率：只要协议是真实意思表示、内容不违法，且未超过一年撤销权除斥期间，法院基本判令继续履行
  2. 协议撤销类——零支持率：样本中 18 件以欺诈、胁迫、显失公平为由起诉撤销，无一获得支持。两大硬核障碍：（a）一年除斥期间；（b）显失公平/等价有偿原则不适用于离婚协议
  3. 抚养费——增易减难：增加抚养费获支持率高（证明子女需要增加即可）；降低抚养费几乎不被支持
  4. 探望/抚养变更——从严：变更抚养、中止/变更探望均需"不利于子女身心健康"的强证据，样本中全部驳回

三、核心争议焦点

序号争议焦点出现频次法院典型态度
1离婚协议是否对双方有约束力、能否单方反悔极高（贯穿全部案由）是，具有法律约束力；反悔须在一年内举证欺诈、胁迫
2显失公平/等价有偿能否作为撤销理由高离婚协议不同于一般民事合同，不能以显失公平撤销
3撤销权是否超过一年除斥期间高超期一律驳回
4房产/存款未过户、一方不履行高判令继续履行 + 协助过户 + 违约金
5协议中"赠与子女"财产能否单方撤销中属一揽子方案，单方撤销须双方合意，驳回
6抚养费能否增加/降低、教育医疗费范围高（15 件）增易减难；教育费仅指公立机构规定收费，不含兴趣班/补习班
7探望权受阻能否中止/变更中须证明不利于子女身心健康，否则驳回
8抚养关系能否变更中须法定不利情形，维持稳定生活环境优先
9假离婚/避税是否影响协议效力中不影响，当事人自担法律后果
10债权人能否以恶意串通撤销财产分割低须证明显著多分 + 损害债权，整体衡量后多驳回

四、法院裁判规则（10条铁律）

规则 1：离婚协议对双方具有法律约束力，应全面履行

  • 依据：婚姻法解释二第8条
  • 案例：(2013)浦民一(民)初字第41114号，协议约定房屋归女方、男方分期补偿 30 万，男方未履行，法院判过户 + 违约金
  • 案例：(2017)沪0117民初5281号，判付补偿款 57.48 万

规则 2：撤销协议仅限于"欺诈、胁迫"，且受一年除斥期间限制

  • 依据：婚姻法解释二第9条
  • 案例：(2020)沪02民终234号 刘某与龚某某，超一年 + 无欺诈胁迫证据，驳回
  • 案例：(2018)沪0115民初36156号 朱健花，超期驳回
  • 案例：(2018)沪0104民初8548号 黄某某，期房理由不成立，超期驳回

规则 3：离婚协议不同于一般民事合同，不适用"显失公平/等价有偿"

财产分割掺杂子女抚养、感情、过错、离婚目的等因素，一方放弃大部分财产不当然构成显失公平。

  • 案例：(2013)杨民一(民)初字第2051号 叶某诉周某，男方放弃全部房产法院认为不显失公平
  • 案例：(2013)宝民一(民)初字第7066号 朱某某诉丁某某，"不能简单以是否等价有偿、公平衡量"
  • 案例：(2012)杨民一(民)初字第5391号 张某与李某，假离婚 + 过错放弃财产不显失公平

规则 4：胁迫的证明须"排除合理怀疑"标准

  • 案例：(2019)沪0112民初18219号 王某某与褚某某，主张 2000 万补偿系胁迫，举证未达排除合理怀疑，驳回撤销

规则 5：假离婚/避税不影响财产分割效力

  • 案例：(2018)沪02民终5184号 梁某与王1，"当事人为规避房屋限购政策而登记离婚并签署离婚协议，理应承担由该行为产生的法律后果"

规则 6：协议中"赠与子女"财产，单方不得撤销

赠与与解除婚姻、抚养、财产分割构成"一揽子"方案，离婚后单方撤销须双方合意。

  • 案例：(2020)沪02民终11199号 张勇与张郁馨，单方撤销赠与子女房屋被驳
  • 案例：(2011)杨民四(民)初字第63号 许某、查某，撤销赠与女儿房产被驳

规则 7：抚养费调整采"实际需要 + 负担能力 + 当地水平"

  • 增加获支持：(2016)沪0117民初1765号 增至 1300；(2019)沪0117民初12104号 增至 5000；(2023)沪0117民初11157号 增至 2000
  • 不增/驳回：(2009)崇民一(民)初字第3699号，无显著增加支出不支持；(2020)沪0115民初74764号，课外培训费不属于基本教育费
  • 标准界定：抚养费含生活费、教育费、医疗费；医疗费仅指门急诊，不含重大疾病；教育费仅指公立教育机构规定收费，不含兴趣班/补习班；标准一般为不直接抚养方月总收入 20%—30%

规则 8：探望权依法保护，变更须证明"不利于子女身心健康"

  • 案例：(2019)沪02民终8460号 李某与刘某某，异地改集中探望，维持探望权
  • 案例：(2017)沪0104民初22961号 周某与胡某某，中止探望被驳
  • 案例：(2014)沪二中民一(民)终字第1694号 缪某，变更探望方式被驳

规则 9：变更抚养关系须法定"不利于子女"情形

  • 案例：(2015)沪二中少民终字第37号 张甲变更抚养被驳
  • 案例：(2016)沪01民终5861号 周俊华被驳
  • 案例：(2018)沪02民终754号 吴某某被驳

规则 10：过错补偿条款有效，金额明显偏高可酌情调整

  • 案例：(2024)沪0107民初17502号 王某与杨某，男方过错自愿补偿 200 万，判付 190 万
  • 案例：(2014)闵民一(民)初字第18222号 沈某某与康某，男方不忠补偿 100 万获支持

五、律师实务建议

5.1 离婚协议撰写重点（防坑清单）

  1. 财产清单必须穷尽：逐项列明房产、车辆、存款、股票、股权、保险、公积金、债权。切忌写"各自名下财产归各自所有""无共同财产"——这会导致未列明财产被视为已分割
  2. 房产过户义务要写死：明确"XX 日前协助办理过户 + 违约金标准 + 税费承担"，避免对方拖延
  3. 给子女的赠与单独成款：明确"为离婚一揽子方案之一，不得单方撤销"，降低被推翻风险
  4. 补偿/折价款约定履行节点：分期付款须写明每期金额、时间、逾期违约责任
  5. 抚养/探望条款要可操作：探望时间、地点、接送方式、寒暑假、就医变通写清楚
  6. 不要用"假离婚"规避限购/避税：法律后果自担，协议有效
  7. 显失公平无法作为反悔借口：协议不可轻易签，签字即严肃

5.2 起诉策略

场景策略要点
对方不履行协议直接诉请继续履行 + 过户/付款 + 违约金；注意不要超过一年再提撤销
想撤销协议必须在离婚登记之日起一年内起诉，且聚焦"欺诈、胁迫"证据，不要主张显失公平
增加抚养费收集"子女实际需要增加 + 对方收入证明"，诉请调高；民办学校/补习班费用难以支持
变更抚养聚焦"对方患重病、虐待、不尽抚养义务、十周岁以上子女愿随己方"等法定情形
中止探望必须证明"探望不利于子女身心健康"，否则驳回

5.3 证据准备清单

  • 协议履行类：离婚证、离婚协议书（民政局备案版）、房产证、银行流水、微信/短信催款记录、违约金计算依据
  • 撤销协议类：受胁迫的报警记录、伤情鉴定、录音录像、证人证言（须达"排除合理怀疑"）；受欺诈的虚假信息证据
  • 增加抚养费类：子女学费/医疗费票据、对方社保缴费基数/收入证明、当地生活水平证据
  • 变更抚养类：对方不适合抚养的医疗/警方/学校证明、子女意愿（十周岁以上）、己方抚养能力证明
  • 探望类：已有的调解书/判决书、对方阻碍探望的报警/执行记录

5.4 诉讼请求设计

  • 履行类：判令被告继续履行《离婚协议书》第X条 + 协助过户 + 支付补偿款XX元 + 违约金（按约定标准，无约定则主张逾期利息）
  • 撤销类：确认《离婚协议书》第X条可撤销/请求撤销 + 依法重新分割（务必在一年内）
  • 抚养费：判令自X年X月起抚养费由XX元/月调整为XX元/月 + 已发生教育/医疗费XX元由被告承担50%
  • 探望：判令按XX方式行使探望权（具体时间、地点、接送）

5.5 庭审表达重点

  1. 咬定"真实意思表示"：对方反悔多主张胁迫/欺诈，我方应强调协议经民政局备案、多份文件一致、签字自愿
  2. 区分离婚协议与一般合同：对方若以显失公平抗辩，立即援引"离婚协议掺杂身份、感情、子女因素，不适用等价有偿"的裁判规则
  3. 抚养费聚焦"三要素"：实际需要、负担能力、当地水平，而非单纯比对方收入
  4. 子女利益最大化：抚养/探望争议一律回归"有利于子女身心健康"
